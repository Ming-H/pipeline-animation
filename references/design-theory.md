# 设计理论：这张图为什么长这样

从 `examples/r1_pipeline.html` 及其衍生图（RAG 纠错环、多阶段训练管线等）反推出的设计规范。
写新图拿不准布局/配色/节奏时读这里；只想要参数速查去 [config-reference.md](config-reference.md)。

## 1) 画布与视觉层级

- **1920×1080**：X / 小红书视频的原生分辨率，MP4 导出零转码；2x 海报导出即 3840×2160。
- **黑底 `#020617`**：暗环境下发光元素的对比度最大化，对标推特流行的 "dark-mode 架构动图" 视觉语汇。
- **纵向四层分区**（自上而下）：
  | 区 | y 范围 | 职责 |
  |---|---|---|
  | 标题区 | ≤100 | title/subtitle/legend，引擎自动渲染 |
  | 支线叙事区 | 130–330 | 支线节点、说明框、涌现标注 |
  | **主线** | **620** | 核心管线，画面纵向 57% 处（≈黄金分割），视线自然先落于此 |
  | 注脚行 | 790 | 芯片（chips），主线的参数注脚 |
- **横向**：主线节点 170 → 1830 均匀分布，两端留白对称，视觉重心居中。

## 2) 颜色语义学（六色 PAL，不许造新色）

| 色 | 值 | 语义 |
|---|---|---|
| cyan | `#22d3ee` | 模型 / 数据 / 最终产出 |
| violet | `#a78bfa` | 标准 / SFT / 校验 |
| amber | `#fbbf24` | 流水线 / RL 循环 / 迭代 |
| rose | `#fb7185` | 决策 / 奖励 / 风控 |
| orange | `#fb923c` | 中间产物 / 数据流 |
| slate | `#94a3b8` | 默认边 / 弱文本 |

- **为什么锁死六色**：暗底可读的色彩数上限≈6；legend 只声明本图用到的语义子集。
- **跨图语义一致**是隐性资产：观众看你的第二张图时零学习成本（同一套"cyan=产出、amber=循环"的肌肉记忆直接复用）。
- 与出版级论文图的蓝(proposed)/绿(improve)/红(baseline)语义色板同一思路的暗色版——色彩承载语义，不做装饰。

## 3) 动效叙事学（scenes 分镜）

- **一个 scene = 一句讲解词 + 一组点亮元素**。字幕是给观众的解说词，`on:[id...]` 是这句词对应登台的演员。
- **节奏参考**：开场 0s → 输入 1.2s → 支线 3.4s → 支线结论 6s → 主线每阶段 +3.5s → 终点 24.4s → 尾帧 30s。
  - 每阶段 3.5s ≈ 观众读完一个节点标题+两行副标题的时间；快了读不完，慢了拖节奏。
- **时序哲学**：先结构（节点弹性入场）→ 再关系（连线生长）→ 再生命感（粒子流动/轨道旋转）→ 最后战果（指标数字滚动+冲击波）。
- **尾帧惯例**：`{t:末尾, cap:'—— 流水线持续运行中（↻ 重播）——'}` 无 on——开放式结尾，暗示系统常驻，不是"演完了"。

## 4) 排版规格

- **节点三行制**：title(y-24) / sub(y+2) / sub2(y+24)；title ≈16px，sub ≈11-12px。超过三行就拆节点或挪 chips。
- **间距红线**（lint 强制）：同排节点横向净距 ≥40；芯片净距 ≥8；pop/note 不进 y≤100 标题区；所有元素不出 1920×1080。
- **轨道环** rx≈160 ry≈92：横向椭圆顺应横向画布；双层环用同心+`reverse:true` 反转表达"内外两股力"（如规则奖励 vs RLHF）。
- **指标数字滚动** dur≈1.8s：从 0 起跳到终值，比直接显示终值更有"战绩感"——动画媒介的独特修辞。

## 5) 工程哲学：引擎冻结、只写 CONFIG

- 历史 bug 100% 出在引擎层，数据层零 bug → **冻结高风险层，把变化收敛到低风险层**。
- lint 把排版红线变成机器断言（E01–E09）：设计规范不靠人眼靠检查——间距、重叠、引用、越界全部静态可判。
- 模板必须脚本搬字节（`cp`）：手打会剥行尾空格、漏 CSS 块——"复制品"和"重写"在字节层面必须等价。

## 6) 静态海报模式

- `?t=终态` + deviceScaleFactor 2 截图 = **3840×2160 出版级静态图**（export_poster.py 自动藏控件）。
- 对应学术图的 dpi=300 纪律：动图（讲解）与海报（README / 文章配图 / 知乎头图）**同源不同壳**，一次 CONFIG 两种交付。
